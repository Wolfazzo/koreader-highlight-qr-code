# koreader-highlight-qr-code

“Generate QR Code” has been added to every panel that displays a highlight. Normally, we can only generate a QR code within the book itself—either immediately after selecting a highlight or by clicking on it again—using the dedicated menu. However, when viewing highlights via the Bookshelf tab and clicking on them—or via Koreader’s default list of all highlights, or even long highlights via AnnotationViewer and the clickable random highlights in the Bookshelf module—we cannot generate the QR code. At the request of a friend who’s an Instagram enthusiast, this patch allows you to do just that. Tested on a Kindle PW on January 11 and K-Reader Desktop.
